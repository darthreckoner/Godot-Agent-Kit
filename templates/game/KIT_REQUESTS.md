# KIT_REQUESTS.md

Changes this game needs from Godot Agent Kit. Agents add entries here instead of editing
`addons/agent_kit/`. The designer reviews them and turns accepted ones into tickets in the kit
repo. After the fix ships in a new kit version and is reinstalled, mark the entry done.

## Entry format
### [Short title]: open | ticketed | done | declined
- **Problem:** what the game tried to do and what stopped it.
- **Workaround:** what was done in `game/` meanwhile, or "none, task stopped".
- **Proposed kit change:** the smallest change that would solve it.
- **Why it is reusable:** why other games would need this too, not just this one.
